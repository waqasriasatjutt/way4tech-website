# /guides/ and /apps/ are deliberately NOT disallowed here.
#
# Both are served with "X-Robots-Tag: noindex" (see public/_headers), and a
# Disallow would defeat that: a crawler told not to fetch a URL never sees the
# noindex on it, so a link from anywhere else can still put the bare URL in
# results with no description under it. Allowing the fetch is what gets them
# dropped and kept out.
#
# /apps/ additionally has to stay fetchable because Google Play reviews each
# app's privacy policy at its public URL.
