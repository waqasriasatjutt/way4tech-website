The till runs in a browser, and a browser is not allowed to talk to a USB port. That is the whole reason Odoo sells an IoT Box: something on the counter has to sit between the web page and the printer. In Community without one, the only hardware the till can drive directly is an Epson printer with ePOS on the network. For a cafe that already owns a USB thermal printer with a cash drawer cabled to it, that means buying new hardware or printing from the browser dialog for every ticket. The WT POS Hardware Bridge add-on takes another route: a small free Windows program on each till PC does the talking, and the till sends it the work.

## How it fits together

The browser running the till sends each job to the agent at `http://127.0.0.1:8171`, on the same computer. Odoo itself never connects to the PC. The address on the till must be 127.0.0.1, localhost or [::1] with a port between 1024 and 65535, and anything else is refused when you save, because the agent only listens on the computer it runs on.

What the agent does with each job:

- **Receipts** are printed as an image in ESC/POS on USB, serial or network printers, so any script and the logo print exactly as on screen.
- **Cash drawer** opens on cash payments and on cash in or out, through the receipt printer or its own port.
- **Scale**: weighed products read the weight from a serial scale.
- **Pole display**: the last line and the total on a 2x20 customer display.
- **Kitchen and bar printers** take preparation tickets by name.
- **Back-office PDFs** print silently to a Windows printer for users who turn that on.

The till also gets the cash drawer and scale switched on in its data when the bridge provides them, so those standard Odoo buttons work without an IoT Box.

## Turning it on for a till

Point of Sale, Configuration, Settings, then Connected Devices. Pick the till at the top of the page and switch on **WT POS Bridge**. The options are the agent address, whether receipts go through the bridge and under which printer name ("receipt" means the receipt printer chosen in the agent), the cash drawer, the scale, the pole display, and **Browser print when the bridge is down**.

## The four step checklist

Open Point of Sale, Configuration, **WT POS Bridge setup** on the till PC itself (managers only), or the Setup checklist and pairing link in Settings. Each step ticks itself from what the agent answers, and Check again asks once more.

1. **Install the agent.** A download button for the Windows installer. It needs no admin rights and starts from the Start menu.
2. **Pair this computer.** Ties the agent to this Odoo.
3. **Devices found.** The agent finds receipt printers, COM ports and a scale by itself, and network printers on port 9100.
4. **First receipt printed.** Print a test or sell something.

Pairing works through a six digit code. The agent only accepts it after the person at the PC clicks Allow, and only from the Odoo that asked, so a pairing cannot be pushed onto a till from somewhere else.

In the agent's settings you name the printers. The till refers to them by those names: `receipt` for receipts, `kitchen` or `bar` for preparation printers.

## In the till

With the bridge on, a printer icon sits in the top bar of the till: green when the agent answered, red when it did not. Clicking it opens the bridge dialog. When the agent is missing it says so, offers the download, and warns that Chrome or Edge may ask to allow access to other apps and services on the device. With the agent running the same dialog pairs and runs test prints.

## Kitchen and bar printers

Add a preparation printer, choose **Use a printer on WT POS Bridge** as the type, and give the bridge printer name exactly as it is in the agent. Pick the product categories it prints as for any Odoo preparation printer and attach it to the till.

## When the agent is not there

The till never stops because of a printer. A kitchen ticket that cannot go out shows Printing failed with the printer's name and two choices, Continue and Retry. A receipt falls back to the browser print dialog when the fallback option is on.

<Shot src="/odoo-guides/odoo-pos-printer-without-iot-box/ui-dialog-1.webp" alt="Printing failed dialog in the till: Kitchen Pass, this computer is not paired with WT POS Bridge, click the printer icon at the top of the POS, with Continue and Retry buttons" width={1440} height={900} caption="A failed kitchen print names the printer and says where to click." />

## Silent printing from the back office

Each user can open their Preferences and turn on **Silent printing through WT POS Bridge**, with an optional Windows printer name. Invoices, delivery slips and other PDF reports then go straight to that printer through the agent on their own PC instead of downloading. **Pair this computer** opens the same pairing screen as the till.

<Callout title="Limits">
The agent runs on Windows only. A Mac, a Linux PC or a tablet till cannot use it and prints through the browser instead. Each till PC needs its own agent and its own pairing. The agent is a separate free download from way4tech.com/posbridge; the Odoo add-on is what you buy.
</Callout>

## Setting up a counter, in order

1. Install the add-on and switch on WT POS Bridge for the till in Settings.
2. On the till PC, open WT POS Bridge setup and download the agent.
3. Let the agent find the devices, name the receipt and kitchen printers.
4. Pair the computer with the code, then print a test receipt.
5. Add preparation printers of the bridge type for the kitchen and the bar.
6. Turn on silent printing for the back-office users who print invoices.
