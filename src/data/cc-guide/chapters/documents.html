Drawings and their revisions, reviews, transmittals, the distribution matrix, requests for information and submittals.

Tip

Every section follows the same pattern: where the menu is, what it is for, who uses it, a picture of the list, a picture of a typical record, the important fields, the stages, the buttons and the linked records. On the live screens, the ? button next to the pager opens the same kind of help for the screen you are on.

Documents

Where: Documents

What it is for: One line per drawing with its current revision worked out from the revisions issued.

Who uses it: Project Manager, Site Engineer

Key steps:

  1. Press New, enter the number, title and discipline.
  2. Press New Revision to add a revision.
  3. Select drawings and press Issue on a Transmittal to send the current set.

The list shows: Drawing Number, Title, Project, Discipline, Originator, Current Rev, Status Code, Review, Superseded, Current Revision Date, Revisions, Status.

A typical record. Click any line to open it. This is "SA-3100 Rev C General arrangement, Level 3":

The important fields

Field What to enter Where it comes from
Status Nothing, it fills in by itself. Worked out by the system.
Drawing Number As printed in the title block. The designer numbers it; we do not renumber it. You enter it.
Rev As printed in the title block: P01, C02, A, B. Copied from a linked record.
Title Type it. You enter it.
Project Pick from the list. The Projects list.
Discipline Pick from the list. The Drawing Discipline list.
Type Choose one: General Arrangement, Plan, Section, Elevation, Detail, Schedule, Setting Out, Sketch. You enter it.
Phase Pick from the list. The Construction Phase list.
Originator The practice that draws it and owns its revisions. The Contacts list.
Scale 1:50, 1:100, NTS. You enter it.
Sheet Size Choose one: A0, A1, A2, A3, A4, Other. You enter it.
Current Revision The highest revision that has been issued. Drafts do not count; a drawing the designer is still working on is not one the site may build from. Worked out by the system.
Current Revision Date The date on the drawing, not the date it was typed in here. Copied from a linked record.
Status Code S0 to S4, A, B, C, AB or the codes set up under Configuration. Copied from a linked record.
Revision Scheme How the next revision code is suggested. The title block always wins; this only fills the field. You enter it.
Revisions Add lines in the table. Lines you add here.

Stage What it means
Not Yet Issued The record is at the "Not Yet Issued" stage.
Preliminary The record is at the "Preliminary" stage.
For Construction The record is at the "For Construction" stage.
Withdrawn Taken back. Kept for the record.

Buttons

Drawing Revisions

Where: Documents › Drawings › Drawing Revisions

What it is for: Every revision of every drawing, current and superseded.

Who uses it: Document controllers.

Why it matters: History of each drawing.

Key steps:

  1. Press New, pick the drawing and attach the file.
  2. Press Issue.
  3. Press Request Review if the design team must review it.
  4. Press Build Transmittal to send it to the distribution list.

The list shows: Drawing, Revision, Status Code, Superseded By, Review, Project, Date Issued, Purpose of Issue, What Changed, For Construction, Current, Sent, Status.

A typical record. Click any line to open it. This is "SA-3100 Rev C":

The important fields

Field What to enter Where it comes from
Drawing Pick from the list. The Drawing Register list.
Revision As printed in the title block: P01, C02, A, B. You enter it.
Order The order the revisions came in. Set automatically; only change it when a designer has reused a letter. You enter it.
Purpose of Issue What the designer issued it for. A drawing marked preliminary is a drawing the site must not build from. The Purpose of Issue list.
Status Code S0 to S4, A, B, C, AB or the codes set up under Configuration. The Document Status Code list.
For Construction Ticked by hand or by a transmittal issued under a purpose that authorises construction. You enter it.
Date Issued The date on the drawing, not the date it was typed in here. You enter it.
Date Received When it reached us. The gap between this and the issue date is a delay somebody else caused. You enter it.
Issued By Defaults to the drawing originator. The Contacts list.
File Upload the file. You enter it.
What Changed The revision cloud in words. "General revision" helps nobody. You enter it.

Document Register (Excel)

Where: Documents › Drawings › Document Register (Excel)

What it is for: Downloads the document register as an Excel file.

Who uses it: Document controllers.

Why it matters: Share the register with the client.

This menu downloads the document register as an Excel file straight away. There is no screen.

The file has two sheets:

  1. Register: one row per drawing with the current revision, its status code, the review state, the superseded revisions and how many times it was sent.
  2. Revision history: every revision of every drawing.

Tip

To export one project only, open Documents › Drawings › Drawing Register, filter to the project, select the drawings and use Export Register.

Transmittals

Where: Documents › Issue and Distribution › Transmittals

What it is for: Transmittals: the record of documents sent to someone, with purpose of issue.

Who uses it: Document controllers.

Why it matters: Proof of who received what and when.

Key steps:

  1. Press New, or use Issue on a Transmittal from the register.
  2. Pick the recipient and purpose of issue.
  3. Press Issue; then Acknowledged when they confirm receipt.
  4. Press Response Received if a reply was required.

The list shows: Reference, Date Issued, Project, Issued To, Purpose of Issue, Format, Documents, Response Due, Status.

Requests for Information

Where: Documents › Queries and Approvals › Requests for Information

What it is for: Requests for information to the designer or client, with due dates and answers.

Who uses it: Site Engineers, Document controllers.

Why it matters: Unanswered RFIs delay work and support claims.

Key steps:

  1. Press New, write the question and the required-by date.
  2. Press Raise to send it.
  3. Press Mark Answered when the reply arrives, then Close.
  4. Use Route to Variation if the answer changes the work.

The list shows: Priority, Reference, Subject, Project, Category, Raised To, Date Raised, Required By, Age (days), Answer Changes Scope, Activities, Status.

A typical record. Click any line to open it. This is "RFI-019":

Project An RFI is evidence of when a question was asked on this job, so the project cannot be deleted while RFIs stand against it. The Projects list.
